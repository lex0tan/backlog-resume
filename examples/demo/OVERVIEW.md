# Demo workspace

A small workspace that shows every level of the backlog model: a project with an
index and workstreams (`shop`), a subproject inside it (`mobile`) and a flat
project with a single file (`docs`). The list below is generated by
`/backlogs` and rewritten with `overview --write`; everything outside the
markers is yours.
